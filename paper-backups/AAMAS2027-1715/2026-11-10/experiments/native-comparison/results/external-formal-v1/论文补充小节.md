# 可补入论文的实验小节（受控操作配置）

## 实验目的与设置

为检验 TxnMemBench 对真实记忆系统的适用性，并比较共享记忆一致性保障，本文增加第三方系统问题发现实验与一致性对比实验。被测对象为 TxnMem 的 SQLite 实现、Mem0 2.0.18、固定提交版本的 G-Memory 与 A-MEM。第三方系统使用原生记忆 API 与真实存储；通过确定性嵌入和固定模型响应控制内容变化。Mem0 关闭自动推理抽取，A-MEM 固定不触发模型驱动演化，G-Memory 使用明确声明的任务记录检索参数。因此，本实验评价显式记忆操作路径对应用一致性契约的满足情况，不评价默认完整智能体流程或语义记忆质量。

六类工作负载由现有采样器参数映射为可通过公共接口执行的简化程序，包括共享可见性、交错原子性、并发版本替换、执行者策略与作用域、跨智能体来源传播和混合工作负载。每类执行50次；部分参数不适用于原生接口映射，实际程序结构存在重复，不能解释为每类50种独立结构。正常对照采用无故障串行执行，扰动实验采用随机或定向的操作边界交错与逻辑任务中断，不涉及进程崩溃或提交内部交错。

对于不具备原生能力映射的工作负载，报告不支持而非通过或失败；对于原生接口异常，单列运行错误。两个实验共享部分相同输入与原始执行证据。合计3300条执行记录，另有60次反例重放；全部记录通过摘要核验及从原始观测重新判定的审计。

## 实验一：第三方系统问题发现

普通无故障测试未在可判定案例中发现应用契约违规。随机扰动在 Mem0、G-Memory、A-MEM 中分别发现95/150、45/100、145/200条违规案例；定向测试分别发现150/150、100/100、200/200条。Mem0 共暴露4类问题：未完成任务数据提前可见、任务中断后数据残留、部分更新以及失效派生残留。G-Memory 在可映射范围内暴露前3类问题；A-MEM 另暴露竞争版本并存，共5类。

按预先固定的执行顺序，各系统定向测试均在第1次预算尝试发现违规，随机测试均在第2次；普通测试在300次预算尝试内未发现。该序号含不支持与错误的预算项，各违规类型的首次发现序号另表列出。每个系统每类违规选取一份完整见证，在新建存储上重放5次，共60/60次成功复现。

这些结果表明，TxnMemBench 可以在原生记忆操作中给出可重放的应用契约缺口，而普通串行功能测试不足以暴露这些缺口。由于普通测试与扰动测试的故障覆盖不同，随机与定向的有效扰动数量亦有差异，本结果不用于证明同等故障预算下的搜索效率优势。被测对象未必承诺任务级事务语义，故应用契约缺口也不等同于违反其自身API保证。

## 实验二：共享记忆一致性比较

在四系统共同支持的共享可见性与交错原子性两类负载中，每类50次定向执行，TxnMem均为0/50次违规，Mem0、G-Memory与A-MEM均为50/50次违规。在跨智能体来源传播负载中，TxnMem为0/50，Mem0与A-MEM均为50/50；G-Memory无原生来源撤销映射，记为不支持。以外部来源图计算的242条受影响派生为分母，TxnMem残留0/242，Mem0与A-MEM均残留242/242。

并发版本替换中，TxnMem为0/50次违规，A-MEM为50/50。Mem0的50次定向执行均因重复删除同一旧记忆触发原生错误，不能计算该类一致性违规率；G-Memory不支持所需版本操作映射。执行者策略与混合负载仅能用于TxnMem自检，其结果均为0/50，不能支撑相应负载的跨系统优势结论。

各系统在自身支持的无故障串行控制范围内，正常完成率均为100%，误中止率均为0%。正常完成要求两智能体任务均结束且预期内容正确、被替换内容消失；误中止以正常逻辑任务为统计单位。该结果排除了在所测控制条件下依靠全量拒绝获得零违规的情况，但不构成并发活性或任务质量保证。

综合上述结果，在所测受控配置与共同可比工作负载中，TxnMem较第三方原生记忆接口更充分地满足了应用要求的任务可见性、操作中断一致性及来源失效闭包。零次观测违规不能推广为任意调度、默认生产配置或无限执行中的零违规保证。
