# TxnMemBench Core

TxnMemBench is a dependency-free, deterministic benchmark for shared Agent
memory correctness. The controlled suite contains eight workload families and
five replay variants. `expected_outcome` is not generated by the workload
generator; `src/txnmem_reference.py` independently computes the oracle.

## Run tests

```bash
python3 -m unittest discover -s tests -v
```

## Generate and replay

```bash
python3 src/txnmem_experiment.py generate \
  --out data/generated_instances.jsonl --seeds 10

python3 src/txnmem_experiment.py run \
  --instances data/generated_instances.jsonl \
  --results results/replayed.csv
```

The compatibility commands `pilot` and `formal` remain available:

```bash
python3 src/txnmem_experiment.py pilot --out-dir . --seeds 10
python3 src/txnmem_experiment.py formal --out-dir . --seeds 20
```

## Full experiment

```bash
python3 src/txnmem_experiment.py experiment \
  --config configs/workload_families.yaml \
  --out-dir . --seeds 10
```

The command writes:

- `data/generated_instances.jsonl`
- `data/reference_oracles.jsonl`
- `results/experiment_results.csv`
- `results/summary.json`
- `results/coverage.json`
- `results/mutation_report.json`
- `results/schedule_baseline.json`
- `results/realism.json` (reports `not_supplied` until a trace is provided)
- `results/figures/violation_rate.svg`
- `results/figures/repair_recall.svg`

## Trace-grounded adaptation

`src/txnmem_trace.py` accepts normalized memory events from an external Agent
workflow and converts them into TxnMem operations. It is an adapter boundary,
not a claim that τ-bench, AppWorld, or LoCoMo already provides policy-churn,
failure-schedule, or provenance ground truth.

## Public compatibility API

`src/txnmem_experiment.py` preserves `generate_instance`, `run_instance`,
`check_invariants`, `run_suite`, `write_jsonl`, and `write_csv`, as well as the
`generate`, `run`, `pilot`, `formal`, and `experiment` CLI commands.
